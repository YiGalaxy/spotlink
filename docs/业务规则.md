# 现货通业务规则

本文记录已经实施的规则；后续交易、合同、顾问节点按实际实现补充。

## 库存登记与维护

- 归属企业取自登录身份，不接受调用方指定其他企业。
- 仅启用的具体叶子品类和启用的交收仓库可登记。数据库外键拒绝孤立品类、仓库关联；逻辑删除和停用由业务服务拦截。
- 数量大于零，最多 15 位整数、3 位小数，非法精度在服务和接口写入前拒绝。数量不做隐式单位换算，单位由品类继承，显式不一致时拒绝。
- 规格按品类 schema 校验必填、数字或文本类型；百分含量在 0 到 100 之间。中文扩展字段保留，规格整体不超过 16 KB。
- 登记为在库，初始总量等于可用量、冻结量为零。本地演示暂不包含仓库确认收货步骤。
- 数量、仓库、单位不可通过描述编辑接口修改。未冻结时可修改描述和同单位的有效品类；冻结时仅可修改备注。
- 同品类编辑由服务端保留未回传的扩展规格键；schema 定义字段继续校验。品牌、产地与备注可清空。历史品类停用后仍允许仅改备注。
- 库存视图返回版本；新页面提交读到的版本，服务端拒绝旧表单覆盖，实际更新同时检查乐观锁。兼容旧客户端未传版本的调用，不将它宣称为表单版本保护。
- 有冻结量时不能注销；已交收或已注销不能继续编辑。注销保留原记录，页面合计不将已注销数量计入现存货物。

## 数量守恒与显示

- 数据库 CHECK 保证总量 = 可用量 + 冻结量，三个口径均非负。
- 冻结减少可用量、增加冻结量，总量不变；释放反向执行；消耗减少总量和冻结量。
- 数量更新检查乐观锁影响行数，冲突中止当前事务；业务可刷新后重试。
- 部分消耗关闭原冻结记录，为剩余部分建立新的冻结记录。关闭记录不能再次释放或消耗。
- 库存接口将小数序列化为字符串，前端按千分之一整数计算合计；吨、千克分别展示，不跨单位相加。

以上规则已有单元、隔离数据库和浏览器验收；完整交易过户、并发取消与双方签署仍属于后续节点，不能以库存验收代替。

## 企业与运营授权

- 企业仅已通过审核时可登录及使用已有令牌；待审核、驳回、冻结、注销均拒绝。冻结后下一次请求立即失效，解冻恢复已通过状态。通过审核仅适用于待审核或已驳回；驳回仅适用于待审核；冻结/解冻不能通过重新审核绕过。
- 冻结必须说明原因，原因随提交后审计留存；未提交或回滚不记成功审计。企业审核与账号/角色变更通过数据库版本锁串行化，操作失败时版本与业务一并回滚。
- 账号状态只接受禁用、正常、锁定。禁止禁用自己，以及移除或锁定最后一个有效平台管理员。并发撤权在相同事务锁下重新检查最后管理员。
- 企业账号不能授予平台 `admin:*` 权限，也不能持有其他企业的私有角色。平台角色分配先验证所有角色，失败保留原授权。
- 授权缓存键包含数据库提交版本；迟到旧查询只能写入旧键。事务内权限读取绕开共享缓存，回滚不发布未提交授权；Redis 故障时读数据库，撤销不依赖 Redis 删除成功。数据库外手工修改授权须同步推进版本，正式运营使用管理接口。
- 开发初始化仅为新建账号授初始角色，重启保留既有密码、状态和已调整角色；新增权限由数据库迁移声明。
- 前端导航与写操作按权限码显示，后台请求仍独立鉴权。资料每 15 秒及重新聚焦刷新菜单；服务端撤销即时生效，页面菜单刷新可能稍晚。

## SELL 挂牌

- 卖方必须指定本企业可交易的库存单。品类、商品名、品牌、产地、规格（含中文扩展键）、单位及交收仓库由服务端继承；请求中的同名字段不能覆盖库存。品类须为启用叶子，源仓库须启用。
- 数量规则与库存一致；固定单价大于零、最多 15 位整数和 4 位小数，写入前拒绝额外精度及溢出。未指定价格类型时按有无单价推断，推断后的定价同样校验；面议不保留旧报价。
- 支持 AUTO 和 MANUAL，默认 AUTO；买方不支持 MANUAL。挂牌截止时间必须晚于现在，交收方式只允许自提或送到。
- 发布、库存冻结、冻结归属关联共同提交或回滚。源库存的读取版本与冻结版本必须一致；并发描述修改或数量变更导致冲突时整个发布失败。
- 只冻结发布数量，总量不变；撤回释放剩余冻结。冻结异常不能被吞掉后记成撤牌成功，挂牌的状态更新检查乐观锁行数。存在待确认摘牌时目前阻止撤回，其独立订单预留与剩余撤回规则继续 C25–C26。
- 页面只展示可信库存摘要，定价/面议使用字段订阅切换；数量及价格按小数字符串传输，避免大数浮点损失。
