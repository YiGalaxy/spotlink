# 现货通业务规则

本文记录已经实施的规则；后续交易、合同、顾问节点按实际实现补充。

## 库存登记与维护

- 归属企业取自登录身份，不接受调用方指定其他企业。
- 仅启用的具体叶子品类和启用的交收仓库可登记。数据库外键拒绝孤立品类、仓库关联；逻辑删除和停用由业务服务拦截。
- 数量大于零，最多 15 位整数、3 位小数，非法精度在服务和接口写入前拒绝。数量不做隐式单位换算，单位由品类继承，显式不一致时拒绝。
- 规格按品类 schema 校验必填、数字或文本类型；百分含量在 0 到 100 之间。中文扩展字段保留，规格整体不超过 16 KB。
- 登记为在库，初始总量等于可用量、冻结量为零。本地演示暂不包含仓库确认收货步骤。
- 数量、仓库、单位不可通过描述编辑接口修改。未冻结时可修改描述和同单位的有效品类；冻结时仅可修改备注。
- 有冻结量时不能注销；已交收或已注销不能继续编辑。注销保留原记录，页面合计不将已注销数量计入现存货物。

## 数量守恒与显示

- 数据库 CHECK 保证总量 = 可用量 + 冻结量，三个口径均非负。
- 冻结减少可用量、增加冻结量，总量不变；释放反向执行；消耗减少总量和冻结量。
- 数量更新检查乐观锁影响行数，冲突中止当前事务；业务可刷新后重试。
- 部分消耗关闭原冻结记录，为剩余部分建立新的冻结记录。关闭记录不能再次释放或消耗。
- 库存接口将小数序列化为字符串，前端按千分之一整数计算合计；吨、千克分别展示，不跨单位相加。

以上规则已有单元、隔离数据库和浏览器验收；完整交易过户、并发取消与双方签署仍属于后续节点，不能以库存验收代替。
