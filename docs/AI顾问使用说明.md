# AI 交易顾问

顾问通过服务端工具读取平台记录。云端和本地兼容模型使用同一套权限与查询逻辑；模型负责理解需求和组织回答，不直接访问数据库或执行交易。

## 可以怎样提问

| 客户需求 | 问法示例 | 回答依据 |
| --- | --- | --- |
| 找货和比价 | 找电解铜，按单价从低到高比较余量和仓库 | 有效公开挂牌，面议单独标注 |
| 数量和预算 | 要20吨，单价不超过70000元/吨 | 同单位筛选，按剩余量判断能否满足 |
| 地点和配送 | 上海交收的有哪些？谁能送到？ | 关联交收仓省市和挂牌交付方式 |
| 商品详情 | 这条挂牌是什么品牌、规格，什么时候到期？ | 指定公开挂牌详情 |
| 运费和成本 | LS…到杭州，10吨，运价80元/吨，运费多少？ | 用户明确提供的费率：10 × 80 = 800元，标明估算 |
| 行情参照 | 这条挂牌报价与最近铜价相比怎么样？ | 挂牌报价与实际成交行情分别展示，说明成交样本量 |
| 库存 | 我们还有多少铜，多少可用、多少冻结？ | 本企业电子库存单及汇总 |
| 交易进度 | 我的订单到哪一步，还有什么待办？ | 本企业订单、合同和待办 |
| 合同核对 | 审查合同CT…的数量、交收和质量异议条款 | 明确请求时才取本企业合同正文，区分原文与建议 |
| 规则与操作 | 面议怎么成交？自提运费、磅差、发票怎么约定？ | 知识库文档编号和标题；未检索到的规则说明未知 |

商品卡片提供“查看挂牌”，打开真实挂牌详情，不直接下单。价格、余量和有效期会变化，成交前以详情和双方合同为准。本方挂牌不能向自己摘牌。

地点表示货物交收仓，不能代替卖家注册地址。平台尚未接入真实物流费率、路线距离、到货时间、质量证书或信用评分，顾问不会编造这些数据。“送到”不代表单价含运费，“自提”不代表运费为零。

## 上下文与采购需求

同一会话会带上最近10轮完整问答，最多10000字符。本地Qwen采用2500字符历史预算、单次最多4条公开挂牌，避免过长上下文拖慢推理；远程检索最多12条。旧价格不会成为新报价，续问会重新查询。

点击“采购需求”保存品种、规格、数量、预算和目的地，即使早期消息已裁剪，仍可作为本会话背景。需求由用户编辑，不生成隐藏的自动记忆；新问题里的条件优先。留空保存清除需求，“新建对话”从新上下文开始。删除会话后不再出现在列表中，数据库采用软删除，不等于物理擦除备份。

会话只属于当前用户，企业同事不能读到；账号更换所属企业后不能继续访问旧企业的会话。问答和计数在同一短事务保存，模型失败不写入半个问答。

## 回答与安全边界

回答先给结论，再用短表格或要点展示依据，使用中文、明确单位和时间。比较表最多4列、8行，单个商品用简短要点；未知信息明确说明，不把面议或缺失费用写成零。页面提供商品卡片和挂牌入口，查询依据默认折叠，并使用中文来源名；主对话区不展示 Token 数或内部工具名。查询时间明确采用北京时间（Asia/Shanghai）。

“第一条”“第2条”等续问依据已展示的服务端商品卡片定位，并重新读取有效挂牌；多条卡片时单说“这条”需要明确对象。思考标签中的内容不会展示，包括本地网关省略开头标签但仍返回闭合标签的情况。模型组织语言仍可能存在错误，关键交易数据应核对卡片、查询依据和挂牌详情。

服务端执行的保护包括：

- 认证身份固定私有数据范围；公开挂牌工具排除过期、关闭和无余量记录，只接受固定筛选及排序，查询值参数绑定。
- 输入最多4000字符，采购需求最多2000字符；控制字符、明显注入和无意义刷屏先处理，不将明显攻击发给模型。
- Redis原子保护：每用户最多10次/分钟、同时1条请求，平台同时最多4条；每轮最多10次工具查询，工具输入与结果设体积限制。
- 模型没有SQL、Shell、任意URL、后台设置、资金或写交易工具。合同正文需要用户明确审查请求，私有记录始终按当前企业读取。
- 商品卡片及允许的链接由查询工具生成。Markdown不加载HTML或外部图片，只有本条回答已查询到的挂牌链接可点击，防止伪造链接与跟踪请求。
- 上游和工具异常只返回安全业务提示，不将密钥、连接细节或数据库异常交给模型与浏览器。凭证仍只在服务端解析。

关键词识别用于减少滥用，不代替权限控制，也不能保证模型输出永不出错。下单、签署、付款、发布、撤销和后台设置均需用户在对应页面操作；顾问不能声称已替客户执行。

## 模型配置与验证

管理员在 `/admin/model` 调整服务地址、实际模型ID、密钥及超时。DeepSeek Flash当前模型列表返回的ID为 `deepseek-flash`，不能仅用显示版本号代替API模型ID。本地服务可填 `http://ollama:11434/v1`、`qwen3:4b` 和占位Key `ollama`；Qwen请求使用 `/no_think` 抑制思考输出。云端配置保留在未跟踪的 `.env`，本地测试可使用后台覆盖。

普通验证使用HTTP替身，不调用真实Key：后端单元、隔离MySQL/Redis集成与容器浏览器覆盖筛选、运费、会话、限流、注入、卡片和安全链接。管理员连接测试和授权的实际问答才调用真实模型。运行输出、聊天轨迹和截图保存于忽略的 `.local/`。
