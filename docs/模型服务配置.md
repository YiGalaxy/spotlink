# 模型服务配置

SpotLink 使用 Spring AI 1.0.0 调用 OpenAI-compatible Chat Completions 服务。浏览器只调用同源 `/api`，真实 API Key 在后端解析。支持聊天与工具调用的本地服务和云端 API 使用同一套配置。

## 后台管理

管理员在 `/admin/model` 读取及修改平台默认模型。读权限为 `admin:advisor`，写入、恢复与显式测试需要 `admin:advisor:write`；内置管理员具备两者，审计员只有读取权限，企业会员不能访问接口。

| 操作 | 行为 |
| --- | --- |
| 保存 | 校验格式与边界，AES-256-GCM 加密 Key，不发模型请求 |
| Key 留空 | 保留现有 Key；首次保存时保留环境配置的 Key |
| 填新 Key | 替换现有 Key；提交结束即清空前端输入 |
| 清除 Key | 删除当前密文并禁止新顾问调用，不回退到 env 中的 Key |
| 恢复环境配置 | 删除整条后台覆盖配置，新请求使用启动时的环境配置 |
| 测试已保存配置 | 发送固定提示与专用工具，返回响应/工具验证状态和耗时；可能产生云端费用 |

所有配置变更及测试写入审计记录，仅保存元数据与 hasKey，不包含明文或密文。每轮模型调用使用独立客户端与不可变快照，补答沿用同一配置。

**配置状态不等于模型可达。** 顾问页面显示“已配置”，实际连通与工具能力需显式测试。模型响应但没有调用探针时，后台显示工具验证尚未完成。

## 环境变量

| 参数 | 初始默认 | 说明 |
| --- | --- | --- |
| `SPOTLINK_ADVISOR_ENABLED` | `true` | 顾问总开关 |
| `SPOTLINK_ADVISOR_API_KEY` | 空 | 云端填真实 Key；无鉴权本地服务填 `ollama` 或 `local` |
| `SPOTLINK_ADVISOR_BASE_URL` | `http://ollama:11434/v1` | API 根地址或带版本前缀的地址，无内嵌凭证、查询参数或片段 |
| `SPOTLINK_ADVISOR_MODEL` | `qwen3:4b` | 服务实际支持的模型 ID |
| `SPOTLINK_ADVISOR_MAX_TOKENS` | `4096` | 单次响应输出上限；后台限制 64–32768 |
| `SPOTLINK_ADVISOR_TIMEOUT_SECONDS` | `120` | 每次 HTTP 模型请求超时；后台限制 5–300 秒 |
| `SPOTLINK_ADVISOR_TOKEN_PARAMETER` | `max_tokens` | 或 `max_completion_tokens`；不会同时发出 |
| `SPOTLINK_ADVISOR_CONFIG_SECRET` | 首次随机生成 | 独立 32 字节 Base64 AES 密钥，用于后台 API Key |

根地址追加 `/v1/chat/completions`，有路径前缀的地址追加 `/chat/completions`。例如 `https://api.openai.com` 和 `https://api.openai.com/v1` 得到同一请求路径；自定义服务填写其真正 API 前缀。`/chat/completions` 完整端点不能作为 BASE_URL。

修改 env 后运行 `start.cmd -NoPause`，Compose 会重建环境改变的后端容器。后台覆盖优先；恢复后才使用 env。

## 本地推理

可选 `local-ai` profile 运行 Ollama，模型端口不对外映射。`setup-local-model.cmd` 完成容器启动、模型下载和无云端凭证时的本地 env 配置，保留数据与后台覆盖。

```powershell
.\setup-local-model.cmd -Model qwen3:4b -NoPause
```

模型数据位于项目的 `spotlink_next_models` 数据卷。推理使用 CPU，速度与可用内存、核数和模型大小相关。默认业务启动不依赖 Ollama；`.env` 地址为 `http://ollama:11434/v1` 且 Key 为 `ollama` 时，`start.cmd` 同时启动并等待模型容器健康。`stop.cmd` 会停止包含模型在内的本项目容器，保留数据卷。后台单独切为本地服务时，先运行模型安装入口启动 Ollama。

宿主服务可用 `http://host.docker.internal:11434/v1`（Ollama）或 `http://host.docker.internal:1234/v1`（LM Studio），确认监听范围可供 Docker 访问。部署时填服务器上的服务地址，无需每个浏览器用户在本机运行模型。

## 升级与凭证恢复

保留已有 `.env` 中的数据库、缓存、JWT 和真实 API Key，不要拿模板覆盖。将模型字段改为兼容协议，再加入独立加密密钥。若旧 env 没有 `SPOTLINK_ADVISOR_CONFIG_SECRET`，且数据库尚未保存后台密文，可在 PowerShell 生成一次：

```powershell
$advisorRng = [Security.Cryptography.RandomNumberGenerator]::Create()
$advisorBytes = New-Object byte[] 32
$advisorRng.GetBytes($advisorBytes)
$advisorRng.Dispose()
Add-Content -LiteralPath .env -Value ('SPOTLINK_ADVISOR_CONFIG_SECRET=' + [Convert]::ToBase64String($advisorBytes))
.\start.cmd -Build -NoPause
```

已有密文时必须恢复原密钥，不能随机重新生成。主密钥缺失或解密失败会明确报错，不静默换 Key；管理员也可重新输入 API Key 覆盖旧密文，或恢复环境配置。数据库与加密主密钥分开备份，两者均不入 Git。

## 调用与失败边界

未配置、停用、上游失败和超时返回明确业务状态；失败轮次不写入悬空消息。网络客户端禁止重定向，错误体与原始异常不暴露给前端或日志，自动重试关闭。

当前是部署者可信的**平台默认服务**，允许管理员填写内部模型地址；不是企业用户任意出站代理。用户个人模型、多引擎代理、全局额度与每用户限流仍在后续计划。普通检查使用 HTTP 替身，不调用真实云端 Key。

## 离线验证

```powershell
.\check.cmd -Task C12 -Mode task -NoPause
```

包括真实 Spring AI SDK 的 URL、鉴权、模型与输出参数、工具消息往返、错误清洗和超时；AES nonce/认证/错 Key；隔离数据库持久化、密钥操作、权限和审计；容器 Chromium 后台页面与响应式验收。真实连接仅通过管理员明确测试按钮或单独本地验证操作发起。
