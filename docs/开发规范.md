# 开发规范

实施节点和验收范围统一以[实施计划](SpotLink实施计划-2026-10-08.md)为准，不另建任务计划。

源码及文档使用 UTF-8、LF；Windows `.cmd` 使用 CRLF。代码按业务职责组织，注释主要说明权限、事务和非显然的边界；新增功能同步必要使用说明。项目依赖与第三方检查在 Docker 中运行。C01 入口拒绝回归仅调用系统 PowerShell 子进程，不安装测试库。

本地提交使用 `类型（范围）：具体动作与结果`，正文说明真实改动、验证和影响，沿用仓库已有人工身份。提交前检查差异、明确暂存本次文件；生成实体记录、渲染 SQL、模型轨迹、日志和凭证只放 `.local/` 或数据卷。

`check.cmd -Task C01 -Mode task -NoPause` 检查当前已实现任务。`-Mode full` 仅回归登记范围并报告最高节点；任何未实现模式非零返回。真实模型只能显式使用 `ai-live`，普通任务与 full 不发模型请求。

执行 `scripts/project-context.ps1` 查看实际状态；`scripts/verify-plan.ps1` 核验两张 75 节点表、登记检查与已实现入口。提交钩子只核验身份、暂存范围与标题，不能替代功能验收。
