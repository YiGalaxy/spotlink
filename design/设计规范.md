# 现货通界面规范

本轮根据用户要求参考淘宝的采购入口结构：公开商城首页、突出搜索、左侧分类、商品卡片和企业入口。品牌、文字与插画使用现货通自己的内容，企业工作台是单独的受保护入口。React、Ant Design 与现有业务接口保持不变。

颜色、字号和响应式规则定义在 `frontend/src/styles/marketplace.css`；Ant Design 主色同步为 `#ce4314`，浅色底上的橙色正文使用更深的 `#b63a10`。背景暖灰、卡片白色、暖橙强调，辅助文字至少 12px，价格使用等宽数字并保留接口精度。交互包含 hover、按压反馈、可见键盘焦点与跳过导航链接，账号菜单支持键盘打开与 Escape 关闭；减少动态效果的系统偏好关闭滚动和卡片位移。

桌面以 1280–1400px 内容宽度呈现，分类 / 主图 / 企业入口三列；1150px 下收起右侧信息，800px 下分类改横向，520px 下商品两列。手机横向分类区域内部滚动，整个页面不应横向溢出。

商品、品类、行情和平台数量仅来自后端；暂无成交行情不补模拟价格。所有品类插画标注“品类示意”，详情注明不是实物照片。新增矢量资源为项目原创代码绘制；后续 C18 图片资源生产仍待实施，不把这次矢量示意当作该节点完成。

首页覆盖加载骨架、无挂牌、搜索无结果、服务失败与重试。浏览与查看挂牌详情无需登录。进入订单管理时保留登录前的目标路径和查询参数。登录默认回商城，工作台、库存、顾问与企业资料继续经过路由守卫和服务端认证。
