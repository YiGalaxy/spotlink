# 当前入口与页面行为

## 现货商城

顶部企业工具栏 → 品牌和主导航 → 商品搜索 → 分类、品类示意主图和账号入口 → 平台成交行情 → 图片品类入口 → 现货商品 → 平台汇总与页脚。

分类、关键词与供应/采购方向保存在 URL，可刷新与后退；结果按最新发布排列，首批显示最多 20 条。卡片显示挂牌方向、品类、商品、规格、单位价格、剩余量和企业。详情弹窗展示挂牌号、企业、规格、仓库、交收与有效期，进入挂牌大厅时定位所选对象；不直接在首页发起交易。

## 登录与企业入口

桌面登录使用辅助插画加表单，手机保留表单。开发账号维持现有演示入口。主动登录返回商城，从订单或受保护功能进入时返回原目标。顶部用户下拉提供企业、库存与退出；运营菜单按权限显示概览、企业审核、账号与角色、订单、审计、模型和知识库入口。

## 验证范围

`scripts/tests/auth-runtime.tests.ps1 -Mall` 构建源码镜像，在独立 Compose 项目通过实际发布 API 建立挂牌，验证账号切换、搜索、分类、采购空状态、详情定位、订单登录返回、390px 页面宽度及故障重试。场景仅落在专用验收库；截图与日志仅 `.local`。顾问布局另由 `scripts/tests/advisor-runtime.tests.ps1` 验证；业务布局和运营入口由 `scripts/tests/auth-runtime.tests.ps1 -Admin -Inventory -Mall` 覆盖五种宽度、键盘导航、只读菜单及冻结/解冻。UI 验收不替代后续交易业务节点。

## 商品图片

电解铜、铝锭、锌锭、碳酸锂、氢氧化锂、精铟各有独立的 gpt-image-2 图片；商城卡片和详情按品类名称选择。首页品类入口来自真实品类 API，点击同步分类 URL；没有挂牌时仍可浏览品类入口，不编造商品或价格。

六张商品 WebP 为 800×800，每张 25–68 KB；首页主图与登录图为 1200×800，分别约 94 KB、210 KB。首屏主图立即加载，商品图延迟加载，固定图片尺寸并提供替代文本。模型实际输出尺寸以清单为准，登录母图实际为 2048×1365。

提示词见[商品图片提示词](商品图片提示词.json)，原图与成品散列、日期、模型和来源见[资源清单](图片资源清单.json)。原图只存 .local/images，Git 仅保留正式 WebP。凭证仍由 gpt-image 技能私有配置读取，不复制进项目。

已准备原图时，Docker assets-tools 运行 scripts/assets/prepare-images.py 生成压缩成品和清单；普通 C18 检查运行本地散列/预算核验及浏览器验收，不调用图片 API。
