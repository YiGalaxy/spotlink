# 当前入口与页面行为

## 现货商城

顶部企业工具栏 → 品牌和主导航 → 商品搜索 → 分类、品类示意主图和账号入口 → 平台成交行情 → 现货商品 → 平台汇总与页脚。

分类、关键词与供应/采购方向保存在 URL，可刷新与后退；结果按最新发布排列，首批显示最多 20 条。卡片显示挂牌方向、品类、商品、规格、单位价格、剩余量和企业。详情弹窗展示挂牌号、企业、规格、仓库、交收与有效期，进入挂牌大厅时定位所选对象；不直接在首页发起交易。

## 登录与企业入口

桌面登录使用辅助插画加表单，手机保留表单。开发账号维持现有演示入口。主动登录返回商城，从订单或受保护功能进入时返回原目标。顶部用户下拉提供企业、库存与退出；运营账号额外显示已有知识库入口。

## 验证范围

`scripts/tests/auth-runtime.tests.ps1 -Mall` 构建源码镜像，在独立 Compose 项目通过实际发布 API 建立挂牌，验证账号切换、搜索、分类、采购空状态、详情定位、订单登录返回、390px 页面宽度及故障重试。场景仅落在专用验收库；截图与日志仅 `.local`。完整计划 C17/C19 还包括顾问等核心页面，当前完成的是用户优先要求的首页、登录与共享导航子功能。
